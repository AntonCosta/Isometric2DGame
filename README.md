# Isometric 2D Game
This is a project meant to showcase my skills in game development as a test to be selected for an Internship. It is to be reviewed and graded by Runic Dices Entertainment.

## Assets
All assets used are from packages I have previously purchased or found for free. All can be used without crediting the original creators. None have been generated by AI.

## AI usage
AI has been used for debugging, performance analysis, and help with understanding and finding documentation and algorithms. I have used the AI chat assistant integrated in my IDE, but it was not allowed to directly interfere with the code or generate any; AI agents have stayed disabled. I have also used ChatGPT for online searches and suggestions. \
For the A* algorithm and the Dialogue system tool window, AI has been more heavily used in helping with the code. They are both topics I am not that familiar with, and I have used both AI and online resources to try to better understand and implement them.

## Task Isometric Player Movement and Input System
The input was handled using Unity's new Input System, mainly using the predefined actions.\
Camera follow has been done using the Cinemachine package.\
Obstacles in the scene have colliders, and all Sprites, that are not the tilemap, are sorted in the scene using the formula Order in Layer = -y * 100. For the player and enemies, this order is calculated dynamically.\

## AI State Machine for Enemy Behaviour
Enemies have the required states: Patrol, Idle, Attack and Chase.\
Enemy logic is dictated by Colliders and the A* pathfinder. The enemy has patrol routes set in the editor, and it will choose one to follow if given multiple, and then randomly cycle between them. \
Obstacles are marked by their layer, and the pathfinder avoids them.

## Personal Specialization

### Combat system
The player can attack with their sword by left-clicking or activate an auto-attacking projectile by pressing Q. Enemies are temporarily stunned by the sword, but not by the projectile.\
Enemies attack in melee when the player is close enough. Both the player and the enemies have a health pool that is shown by the red glow that appears when hurt. The player can heal using H for a limited number of times.\
When the player dies, a restart button appears on the screen.

### Dialogue System
There is an NPC that can be interacted with when in range by pressing E. A dialogue window appears that can be navigated using the prompts, mouse clicks and the space bar to skip the dialogue animation.
There is a tool for editing the Dialogue and Responses, without writing in the JSONs, found in the Tools/DialogueEditor menu. This window has been created following a youtube video series and with the help of the AI chat.
